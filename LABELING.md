# Labeling guideline (write this on Day 1, do not change it mid-way)

Grade each (query, note) pair by asking: "If I had typed this query, would this note have been what I wanted?"

- **2 = highly relevant:** this is the note I was looking for, or it directly answers the query.
- **1 = partially relevant:** related and somewhat useful, but not what I wanted first.
- **0 = not relevant.**

Rules I follow:
1. Judge the note as it is, not the rank it was shown at (the pool is shuffled for this reason).
2. If two notes cover the same thing, the more complete one gets the higher grade.
3. When unsure between two grades, pick the lower one.
4. Do not look at which system returned the note.
